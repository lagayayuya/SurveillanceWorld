# Sécurité

Vous avez trouvé une faille ? Merci de la signaler **en privé**, pas dans un ticket public.

- De préférence par le signalement privé de GitHub : onglet « Security », puis « Report a
  vulnerability ».
- Sinon, par courriel à l'adresse de contact indiquée sur la page « Mentions légales » du
  site.

Décrivez ce qui est touché, comment le reproduire et l'effet possible. N'accédez pas aux
données d'autres personnes au-delà de ce qui suffit à le montrer, et ne dégradez pas le
service.

Le projet est tenu bénévolement : aucun délai de réponse n'est promis, mais chaque
signalement est lu.
